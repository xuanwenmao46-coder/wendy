# Image Treatments

## If The Image Is Strong

- Use it at 45-65% of frame width.
- Let it cross an edge or sit on a virtual surface.
- Add one soft floor shadow or reflection.
- Keep labels away from the product body.
- Use one accent line or proof point, not a HUD cage.

## If The Image Is Medium

- Crop aggressively to the best detail.
- Place it inside a matte poster card.
- Reduce scale and pair with stronger typography.
- Add grain, vignette, and controlled shadow.
- Use it as a supporting asset, not the hero.

## If The Image Is Weak

- Do not use it as a launch hero.
- Convert it into a silhouette or abstract shape.
- Use a designed placeholder/product block instead.
- Ask for official product asset or generate a new render.

## Product Launch Safe Pattern

```text
large product image
+ oversized title block
+ one metric or product claim
+ warm/cool controlled light
+ final lockup
```

## Bad Pattern

```text
small product image
+ multiple feature cards
+ random HUD rings
+ neon glow
+ unreadable tiny text
```
