# Scenario Playbook

Choose one primary scenario per clip. Secondary scenarios can influence style, but the clip should not serve every use case at once.

## Product Launch

Use for AI tools, SaaS launches, product reveal videos, startup demos.

- Core promise: make the product feel desirable and powerful.
- Strong concept: product summon, system awakening, cinematic reveal, hero object activation.
- Content modules: product name, tagline, product visual, one proof point.
- Motion patterns: scan reveal, kinetic title, shape burst, product lockup.
- Avoid: generic HUD decoration, tiny feature cards, weak product images as hero.

## Data Shock

Use for growth reports, investor updates, campaign results, metrics.

- Core promise: make the number feel consequential.
- Strong concept: number impact, graph tear, scoreboard moment, market signal.
- Content modules: big number, delta badge, chart/sparkline, source note.
- Motion patterns: data hit, count-up, badge snap, chart draw, pulse.
- Avoid: decorative chartjunk, slow chart drawing without a conclusion.

## Breaking Explainer

Use for news, explainers, educational shorts, current events, knowledge hooks.

- Core promise: turn complexity into an urgent question.
- Strong concept: breaking stinger into the core question.
- Content modules: keywords, question, lower third, context line.
- Motion patterns: flash stack, slash wipe, ticker, lower-third state.
- Avoid: too many readable blocks flashing too quickly.

## Concept Metaphor

Use for abstract ideas: AI, emergence, security, connection, growth, intelligence.

- Core promise: make an invisible concept visible through behavior.
- Strong concept: chaos to order, signal path, shield absorption, network emergence.
- Content modules: concept word, minimal explanation, abstract system.
- Motion patterns: particle swarm, network draw, word recompose, camera push.
- Avoid: static node diagrams that feel like PPT.

## Brand Drop

Use for fashion, lifestyle, culture, consumer launches, social ads.

- Core promise: create a memorable style moment.
- Strong concept: motion poster, collage cut, oversized type, color slap.
- Content modules: brand word, product/drop name, date, tagline.
- Motion patterns: mask slice, smear transition, poster collage, stinger cut.
- Avoid: clean corporate cards, timid typography, soft generic gradients.

## App Feature Hype

Use for app/SaaS feature videos, website hero clips, product explainers.

- Core promise: make the feature feel fast and useful.
- Strong concept: UI modules assemble like machine parts.
- Content modules: feature name, UI card, callout, interaction state.
- Motion patterns: UI assembly, cursor hit, interaction pulse, match cut.
- Avoid: static screenshots with small unreadable UI.

## CTA / Outro

Use for closing a video, conversion, signup, end card.

- Core promise: leave the viewer with one action.
- Strong concept: final lockup, logo hit, compressed recap.
- Content modules: logo, CTA, URL, one benefit.
- Motion patterns: match cut, logo lock, final pulse, clean out.
- Avoid: adding new information at the end.
