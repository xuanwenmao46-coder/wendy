# Slide Types For Video Clips

Use these patterns as high-level clip skills. Each pattern should be buildable as a HyperFrames/GSAP composition.

## 1. Cover / Keynote Opening

Use for launch videos, section openers, brand films, and first frames.

- Structure: huge title, restrained brand mark, one hero visual or abstract signal.
- Best inputs: product name, tagline, brand palette, optional product image.
- Skippable: product image; replace with type-led or abstract symbol.
- Motion: slow reveal, mask crop, title tracking, subtle atmospheric movement.

## 2. Takeaway / Consulting Slide

Use when the clip needs to communicate one sharp claim.

- Structure: conclusion headline, one proof element, one short explanation.
- Best inputs: claim, proof point, audience context.
- Skippable: proof point; use strong type and a small note.
- Motion: claim first, proof second, context last.

## 3. Data Story

Use for charts, metrics, growth, performance, and insight videos.

- Structure: insight headline, chart or key number, highlighted evidence, source.
- Best inputs: data series, comparison target, conclusion.
- Skippable: detailed data; use big-number proof if only one value exists.
- Motion: reveal axis lightly, animate the meaningful change, then annotate.

## 4. Comparison

Use for before/after, competitor comparison, plan A/B, old/new system.

- Structure: two sides or three columns, shared baseline, highlighted winner/change.
- Best inputs: compared items, criteria, verdict.
- Skippable: detailed criteria; use headline verdict and two visual states.
- Motion: old state enters first, new state overtakes or resolves.

## 5. Timeline / Process

Use for roadmap, workflow, user journey, product mechanism, history.

- Structure: path, steps, key moments, current/future emphasis.
- Best inputs: step labels, dates/order, current stage.
- Skippable: dates; use numbered steps.
- Motion: path draws through time, each step follows with staggered detail.

## 6. Feature Grid

Use for product selling points, capability lists, module previews.

- Structure: product/hero feature plus secondary feature cards.
- Best inputs: feature names, short benefit lines, product image or UI screenshot.
- Skippable: image; use abstract cards and one oversized feature.
- Motion: hero feature locks first, secondary features orbit/settle around it.

## 7. Visual Metaphor

Use when the idea is abstract: growth, connection, security, intelligence, speed.

- Structure: one abstract system, minimal text, labels only where needed.
- Best inputs: concept, desired feeling, key metaphor.
- Skippable: detailed copy; let the visual carry the meaning.
- Motion: object behavior explains the concept, e.g. nodes connect, signal accelerates, shield absorbs.

## 8. Scene Transition

Use for multi-page clips or skill preview galleries.

- Structure: outgoing scene, shared geometry/mask/type, incoming scene.
- Best inputs: previous layout, next layout, transition mood.
- Skippable: custom transition; use clean cut/fade.
- Motion: preserve one shared object, line, color, or type position across scenes.
