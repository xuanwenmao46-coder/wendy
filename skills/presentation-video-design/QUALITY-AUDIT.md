# Presentation Video Quality Audit

Run this before implementation and again before final render.

## Fast Read

- Can the main point be understood in 2 seconds?
- Does the headline say the conclusion, not just the topic?
- Is there one clear first read and one clear second read?
- Would the frame still work as a static PPT slide?

## Visual Hierarchy

- Primary element is visibly larger, bolder, brighter, or better positioned.
- Supporting text is not competing with the headline.
- Captions, labels, and sources are tertiary.
- Alignment creates order; nothing feels randomly placed.

## Layout

- Uses a clear grid, not arbitrary placement.
- Has enough negative space.
- Avoids five equal cards unless the point is a catalog.
- Avoids centered stacks unless intentional.
- Uses proximity to group related information.

## Typography

- Uses defined type roles: display, support, data, metadata.
- Uses one expressive voice and one quiet support voice.
- Avoids default-looking font choices unless explicitly branded.
- Numbers use tabular figures.
- Text is readable at video preview size.

## Data

- Chart type matches the message.
- One value/series is highlighted.
- Gridlines, labels, and decorations are reduced.
- Source/context exists but does not dominate.
- No fake precision or misleading scale.

## Motion

- Animation follows reading order.
- Primary motion is distinct from secondary motion.
- Easing feels intentional, not default-linear.
- Holds are long enough to read.
- Transitions are tied to layout/content, not random effects.

## Anti-Patterns

Reject or revise:

- Generic neon HUD with no semantic role.
- Gradient text used as the main design idea.
- Random glows without light source.
- All elements entering with the same fade-up.
- Decorative charts that do not explain an insight.
- Too many medium-size cards.
- Fonts, colors, and spacing that change per page without a token system.
- Weak downloaded images forced into hero scale.

## Acceptance Bar

The clip is acceptable when it can be described as:

> A strong presentation slide with purposeful motion.

If it is only:

> A web layout with things moving.

Revise the design before rendering.
