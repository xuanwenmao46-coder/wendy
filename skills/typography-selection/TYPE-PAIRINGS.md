# Type Pairings

## Premium Product Launch

- Display: high-contrast serif, elegant editorial serif, or sharp condensed sans.
- Support: quiet grotesk or humanist sans.
- Data: mono with tabular numbers.
- Mood: restrained, spacious, confident.

## Editorial Tech

- Display: condensed grotesk or serious serif.
- Support: neutral sans.
- Data: mono.
- Mood: evidence, rhythm, precision.

## Data Authority

- Display: sober sans or serif.
- Support: compact sans.
- Data: mono or font with tabular numbers.
- Mood: trust, clarity, restraint.

## Maximal Type

- Display: one very bold expressive typeface.
- Support: nearly invisible support type.
- Data: optional mono.
- Mood: loud, cropped, kinetic.

## Anti-Pairings

- Two generic sans fonts.
- Old web serif + old web sans for premium launch.
- Decorative display + decorative body.
- All text in mono unless the concept is explicitly terminal/code.
- Thin tiny labels on video.
